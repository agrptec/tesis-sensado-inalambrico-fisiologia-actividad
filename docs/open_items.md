# Pendientes científicos

## Evidencia pendiente

- Completar S4.7-Ub con espectros singulares, rango efectivo, coherencia por pares, separación de retardos y agrupación de modos no resolubles.
- Ejecutar E0 para cuantificar deriva intra-sesión, variación intersesión, reinicios, reconexiones y estabilidad de la referencia.
- Ejecutar E1 con desplazamiento medido y comparar `Delta H`, `J_real` y `J_sim` para todas las representaciones primarias.
- Ejecutar E2 con fantoma respiratorio sólo después de cerrar el piso instrumental y el régimen de diferencias finitas.
- Repetir la evaluación estática seleccionada en una escena o sesión externa antes de formular una afirmación confirmatoria de transferencia.

## Literatura pendiente de integrar

- Completar la auditoría de OpenLoRa para separar recepción PHY, interferencia y disponibilidad de observables útiles para sensing.
